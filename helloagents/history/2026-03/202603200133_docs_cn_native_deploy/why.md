# 变更提案: 中文文档与原生部署优化

## 需求背景
当前仓库公开文档几乎全部为英文，README 只展示 Docker 启动方式，而仓库内的 `install.sh` 实际已经支持原生二进制 + `systemd` 部署。对希望直接在宿主机运行、避免 Docker 额外内存占用的用户来说，现有文档不够直观，也无法通过一条命令同时完成部署和内存调优。

## 变更内容
1. 将公开文档统一翻译为中文，并补充完整的项目说明。
2. 将 README 的推荐安装路径调整为本机原生部署，Docker 改为备选方案。
3. 在 `install.sh` 中增加运行时内存参数，使“本机一键部署 + 内存限制”可以通过单条命令完成。

## 影响范围
- **模块:** 安装部署、配置系统
- **文件:** `README.md`、`config.yml.example`、`install.sh`
- **API:** 无
- **数据:** 新增/更新知识库与方案包

## 核心场景

### 需求: 中文化项目文档
**模块:** 安装部署
公开文档需要统一为简体中文，降低首次接触项目的理解成本。

#### 场景: 新用户阅读 README
用户首次打开仓库主页。
- 能直接看到中文项目说明
- 能区分推荐的原生部署和可选的 Docker 方案

### 需求: 提供本机一键部署方案
**模块:** 安装部署
用户希望直接在宿主机安装服务并避免 Docker 额外内存占用。

#### 场景: 小内存 Linux 主机
运维人员在 1G 或 2G 内存机器上部署节点。
- 可通过 `install.sh` 一条命令完成原生部署
- 可在部署时同时写入 `gomemlimit` 与 `gogc`

## 风险评估
- **风险:** 文档与脚本参数不一致会导致部署失败或误导用户
- **缓解:** 同步更新 README、配置示例、知识库并执行测试与脚本语法检查
