# API 手册

## 概述
`xboard-node` 作为 Xboard 面板的节点代理，主动调用面板接口拉取配置、同步用户并上报运行状态。

## 认证方式
所有请求均通过节点令牌认证。令牌由配置中的 `panel.token` 提供，并在面板客户端中统一附带。

---

## 接口列表

### 握手接口

#### `POST /api/v2/server/handshake`
**描述:** 一次性获取节点同步策略、WebSocket 配置以及初始化信息。

**请求参数:**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| token | string | 是 | 节点令牌，由客户端自动附带 |
| node_id | integer | 是 | 当前节点 ID |

**响应:**
返回握手结果、推送开关、WebSocket 地址与同步间隔。

### 节点配置

#### `GET /api/v1/server/UniProxy/config`
**描述:** 拉取当前节点的代理配置。

**请求参数:**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| If-None-Match | string | 否 | 使用上次响应的 ETag，支持 304 |

**响应:**
返回协议类型、端口、证书策略、内核日志等级等配置。

### 用户列表

#### `GET /api/v1/server/UniProxy/user`
**描述:** 拉取节点可用用户列表。

**请求参数:**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| If-None-Match | string | 否 | 使用上次响应的 ETag，支持 304 |

**响应:**
返回用户 ID、UUID、设备限制、速率限制等信息。

### 状态上报

#### `POST /api/v2/server/report`
**描述:** 上报流量、在线用户、系统资源与扩展监控指标。

**请求参数:**
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| traffic | object | 否 | 用户流量统计 |
| alive | object | 否 | 用户在线 IP |
| online | object | 否 | 用户在线连接数 |
| status | object | 是 | CPU、内存、磁盘、交换分区 |
| metrics | object | 否 | 活跃连接数、GC、WebSocket 状态等扩展指标 |

**响应:**
成功时返回 HTTP 200。
