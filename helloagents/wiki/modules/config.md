# 配置系统

## 目的
集中管理 YAML 配置、环境变量覆盖、默认值填充和多节点展开。

## 模块概述
- **职责:** 位于 `internal/config`，定义配置结构体、校验规则、日志初始化和多节点配置派生。
- **状态:** ✅稳定
- **最后更新:** 2026-03-20

## 规范

### 需求: 提供统一配置入口
**模块:** 配置系统
所有运行参数必须通过配置文件或环境变量进入进程，不允许在代码中写死敏感信息。

#### 场景: 文件配置
本地部署通过 `config.yml` 运行。
- 支持面板、内核、证书、日志、运行时调优等字段
- 在字段缺失时回填安全默认值

#### 场景: 环境变量覆盖
Docker 模式不挂载配置文件。
- 支持 `apiHost`、`apiKey`、`nodeID` 等环境变量
- 环境变量优先级高于文件中的同名设置

## 数据模型
### `Config`
| 字段 | 类型 | 说明 |
|------|------|------|
| Runtime | object | 运行时内存调优 |
| Nodes | array | 多节点列表 |

## 依赖
- 标准库 `yaml.v3`
- `log/slog`
