# 内核适配

## 目的
统一抽象 sing-box 与 xray-core 的启动、重载和连接管理能力。

## 模块概述
- **职责:** 位于 `internal/kernel` 及其子目录，定义通用接口，并分别实现 sing-box 与 xray 的配置生成、启动和动态用户操作。
- **状态:** ✅稳定
- **最后更新:** 2026-03-20

## 规范

### 需求: 保持多内核一致的服务行为
**模块:** 内核适配
不同代理内核必须对外暴露统一能力，便于服务层执行重载、用户增删和连接关闭。

#### 场景: 启动内核
收到面板配置与用户列表。
- 生成内核配置
- 传入证书路径并启动目标内核

#### 场景: 用户变更
用户列表增删或全量刷新。
- 优先使用内核原子用户更新接口
- 不支持时回退为全量重载

#### 场景: SS2022 凭证校验
面板下发 `shadowsocks` 的 `2022-blake3-*` 配置。
- 在调用 sing-box 或 xray 前校验 `server_key` 与用户密码
- 错误信息需直接指出 `server_key` 或 `user_id`
- 用户热更新失败时拒绝整批变更，避免运行态与内存状态不一致

- `internal/kernel/xray`
- 面板配置模型
